<h1>Григорианский календарь</h1>

Техническое задание по реализации календаря после 1600 года.

# Основная логика работы: 

Пользователю на выбор предоставляется два варианта действий - отобразить календарь указанного года / определить день недели по дате. 

При выборе первого варианта - отображается календарь, разбитый по месяцам. Во втором случае - день недели. 

Основная логика в хранении уникальных календарей и исходя из проверки типа - вывода соответствующего шаблона. 

# Технологии разработки: 

`Java`, `Spring Framework`, `REST`, `JUnit`
